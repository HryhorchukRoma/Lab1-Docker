Мета проєкту

Ознайомитися з принципами контейнеризації, навчитися завантажувати готовий образ Nginx, створювати та запускати контейнер, публікувати порти й підключати локальний каталог вебсайту.

ТЕХНОЛОГІЯ 01

Docker

Платформа для створення, запуску та керування контейнерами. Контейнер забезпечує ізольоване середовище для виконання застосунку.

ТЕХНОЛОГІЯ 02

Nginx

Вебсервер, який обробляє HTTP-запити та передає браузеру статичні файли HTML, CSS та інші ресурси сайту.
